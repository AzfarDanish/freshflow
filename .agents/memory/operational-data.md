---
name: Operational data boundaries
description: Real operational data, deliberate demo removal, and trustworthy AI/OCR requirements.
---

Treat stored records as actual operational data, not disposable presentation fixtures. Normal navigation and reads must not recreate missing records, seed businesses with mock data, or manufacture activity. Recalculate derived risk records from relevant persisted facts.

**Why:** The user requires real persistent operations, truthful outcomes, honest empty states, and complete removal of runtime demo/mock business data.

**How to apply:** Use persisted state for all pages and actual actions for success feedback. Keep decision/audit history distinct from live pending recommendations and open work. A completed staff report is not an inferred inventory adjustment.

Production must not restore demo fixtures or silently repurpose the old demo reset into a real-data wipe. Removing legacy demo data requires a deliberate, backed-up, reviewed migration that preserves legitimate configuration, user records, documents, and unrelated businesses.

**Why:** The production-transition brief supersedes the seeded-demo outcome. Earlier manual inventory entry also marked new records synthetic, so a legacy synthetic flag alone is not reliable evidence that a record is safe to delete.

**How to apply:** Inspect provenance and dependent records, present the migration dry run for confirmation, and stop on ambiguity. Test destructive operations against isolated test data, never the user's current dataset.

Invoice extraction must use deterministic parsing and OCR, never generative AI. Inventory assistants and AI insight explanations are read-only and grounded in permission-scoped, verified records and deterministic calculations.

**Why:** The user explicitly prohibits AI invoice extraction, unrestricted AI SQL, invented quantities/prices/history, fabricated analytics, and automatic inventory posting after upload or processing.

**How to apply:** Require Owner-confirmed actual receiving before stock movements; disclose missing records/costs and cite supporting facts. Keep model answers separate from authoritative numeric calculations and operational mutations.
